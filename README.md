### 🛠️ What I've built

- **Cloud migration**: moved a legacy production Windows Server (SQL Server + ERP, ~800 GB) from on-prem Hyper-V to Azure with minimal downtime.
- **Infrastructure as Code**: shared Terraform / Terragrunt modules for AWS and GCP, plus “blueprints” that deploy a whole app stack from one config file.
- **CI/CD standards**: reusable CircleCI pipelines with OIDC sign-in (no stored secrets), approval-gated production and automatic release tags.
- **HIPAA-ready AWS**: AWS Config with the 130-rule HIPAA conformance pack, KMS encryption and locked audit logs.
- **Load testing**: a k6 tool that raises traffic until the SLO breaks and reports the last healthy level.
- **Large-scale upgrades**: upgraded TIBCO middleware on 100+ servers with Ansible and Bash, with no customer impact.
- **Database release pipeline**: Jenkins pipeline for config-database changes, from dry run to change request to deploy.
- **AI agent platform**: infrastructure for scheduled AI agents in isolated containers, each run limited to its own user's data (ECS Fargate, EventBridge, Lambda, DynamoDB).
- **AI code review in CI**: an automated reviewer on every pull request, driven by one central set of coding, security and healthcare guidelines.
- **Medical document redaction**: a PDF tool that finds patient data, lets a person review it, then redacts it (Textract, Comprehend Medical).
- **GCP platform template**: GKE, Cloud SQL, Firebase Hosting, DNS and alerts, deployed from CI with Workload Identity and no static keys.
- **CloudFormation app stack**: ordered stacks for a full web app (ECS Fargate, RDS, Cognito, Amplify, CloudFront), one template set for every environment.
- **Secure upload portal**: serverless, code-protected file intake straight into a private S3 bucket.
- **IAM automation**: scripts for onboarding, access grants, key rotation, offboarding and audits across AWS accounts.
- **Disaster recovery**: designed and built a service at a DR site, from network topology to app deployment.
